# Claude Code 設定の見直し

あなたは Claude Code のグローバル設定を見直すレビュアーです。ファイルは編集せず、見直しレポートを Markdown で出力してください（出力がそのままレポートファイルになる）。

## 対象
- `~/.claude/CLAUDE.md`
- `~/.claude/agents/`、`~/.claude/skills/`、`~/.claude/rules/`
- 対象期間（末尾に記載）のセッション履歴: `~/.claude/projects/**/*.jsonl`（サブエージェントの履歴を含む。各行の `timestamp` で期間を判定する）
  - 履歴は大きいので、全体を Read しない。まず Grep で対象期間の行やキーワードに絞り込んでから、必要な箇所だけを Read する

## 調べること
1. ユーザーからの訂正・やり直し・強い口調の指摘。その原因になったルールの不足・曖昧さ
2. 繰り返し出てくる依頼・手順のうち、ルール・スキル・フックにできそうなもの
3. サブエージェント・スキルの利用状況（呼ばれた回数、有効な指摘があったか）と、呼ばれていないもの
4. ルール同士の矛盾、守られていないルール、実態に合わなくなったルール

## 出力
- 冒頭に 3 行以内の要約を書く
- 改善案ごとに「問題（根拠となる件数・具体例）」「変更案（対象ファイルと変更内容）」「デメリット・リスク」を書く
- 件数を書くときは、数えた範囲（期間・セッション数）を明記する
- 根拠が薄いものは書かない。改善案がなければ「改善案なし」とだけ書く
- 設定ファイルは public リポジトリで管理されている。変更案の文言には、プロジェクト名・リポジトリ名・機能名・環境構成・個人名を入れず、誰にでも当てはまる汎用的な表現で書く
